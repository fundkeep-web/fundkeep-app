# Code of Conduct

FundKeep is committed to a welcoming, harassment-free community. Be respectful, constructive, and inclusive in issues, pull requests, and discussions.

Report unacceptable behavior privately to the repository maintainers. Reports will be handled promptly and confidentially.

This project follows the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
