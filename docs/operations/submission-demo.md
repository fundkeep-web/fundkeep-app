# Submission Demo

A video is optional for the application form but useful evidence. Record one continuous two-minute walkthrough:

1. Open [FundKeep](https://fundkeep.vercel.app) and show the Testnet label.
2. Connect a Freighter account configured for Stellar Testnet.
3. Create a small savings goal and approve the contract invocation.
4. Deposit the configured test token and wait for confirmation.
5. Show the goal's locked balance and transaction link.
6. Open the activity feed to show the indexed event.
7. Open the contract in [Stellar Expert](https://stellar.expert/explorer/testnet/contract/CBYUMUNDBGT5JTYX62SSFH5NTK2ELLRT2PP3LLZOI757JB4BULDDDFAH).
8. Finish on the [GitBook documentation](https://entity-6.gitbook.io/fundkeep).

Never expose a recovery phrase, private key or production wallet during recording.
